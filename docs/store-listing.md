# Play store listing copy

**This document is the only copy of the listing text.** The Console is where it is pasted, not where
it lives — a value that exists only in a web form cannot be reviewed, translated as a set, or
recovered when someone edits it by accident.

Three scripts read this file, so its headings are load-bearing:

| Script | Reads |
| --- | --- |
| `scripts/play-whatsnew.py` | the `## Release notes` section, rendering every locale's note in the one format the Console's textarea accepts |
| `scripts/notes-gate.py` | the newest `### x.y.z` heading, refusing a merge where it does not match `versionName` |
| `scripts/play-metadata.py` | the whole thing, generating the `fastlane/metadata/` tree the publish workflow uploads |

> **The gate exists because of a real failure.** A release shipped to production carrying the
> *previous* version's release notes: `versionName` had been bumped and the notes had not, nothing
> compared the two, and Play does not allow release notes to be edited on a live release. The
> correction had to wait for the next upload. Renaming a heading is cheaper.

### Full description — 2923/4000

**No health or safety claims.** Urgent is a second chance at a call, not an emergency service, and
the *What it cannot do* section says so; Play's enforcement reads a linked page as part of the
listing, so `index.md` holds the same line.

```
Someone who calls twice in a few minutes probably needs you. Urgent rings for that second call, even when your phone is on silent or vibrate.

HOW IT WORKS

When a call comes in, Urgent looks in your call log for the same number in the last few minutes: 5, 10, 15 or 30, you choose. If it called before, and your phone is about to let the call go by without a sound, Urgent plays your ringtone at your alarm volume and vibrates. If Android won't let it read your ringtone, it plays your alarm sound instead. It stops when you answer or decline, when the call ends, or after a minute. A notification with a Silence button stops it sooner.

The first call stays as quiet as you set it. Only the second one rings. A call you declined counts as the first one too, unless you turn that off.

IT ONLY RINGS WHEN YOUR PHONE WOULD NOT

- Ringer on: your phone rings by itself, so Urgent stays quiet.
- Silent or vibrate: Urgent rings.
- Do Not Disturb: Urgent rings only if alarms are allowed, and stays quiet when your phone's own repeat-callers rule already lets the call ring. If Do Not Disturb lets calls through only from your contacts, Urgent cannot tell who is a contact, so it rings anyway, even when your phone rings too.
- On another call: Urgent stays quiet.

YOUR SETTINGS ARE LEFT ALONE

Urgent never changes your ringer mode, your ring volume or Do Not Disturb. It plays the ringtone on the alarm stream, which silent mode does not mute, so if anything goes wrong mid-ring your phone is exactly as you left it.

FREE, AND NOTHING LEAVES YOUR PHONE

No ads. No account. No server. No subscription. Urgent does not request the internet permission, so it cannot send anything anywhere. It reads the last few minutes of your call log at the moment a call rings, compares one number, and keeps nothing. It stores only its own settings: whether it is on, how many minutes count as "again", whether declined calls count, your theme and your language.

WHAT IT CANNOT DO

Urgent cannot tell why someone is calling. Two calls in a row ring whether they matter or not, and a single call stays silent however important it is.

A call with a hidden number cannot be matched, so it never rings through.

Some phones stop it. Android's battery optimisation can keep Urgent from ringing in the background, and the app takes you to the setting that allows it. On Xiaomi phones Urgent hears about a call only when autostart is on, and the app opens that list for you.

Urgent is a second chance, not a guarantee. If you must not miss a call, keep your ringer on.

PERMISSIONS

- Phone. Tells Urgent that a call is ringing.
- Call log. The caller's number, and whether they called in the last few minutes. Read on the phone, never stored, never sent.
- Notifications. The Silence button while Urgent rings.
- Foreground service. Plays the ringtone while the call rings.

Source available, built in the open: github.com/srednimax/urgent
```

## Release notes (Play's "What's new", 500 chars per locale)

**Don't paste these by hand.** The Console takes all languages in one textarea, tagged by locale,
and `scripts/play-whatsnew.py` renders exactly that from the blocks below:

```bash
python3 scripts/play-whatsnew.py                 # newest version here, to stdout
python3 scripts/play-whatsnew.py --version 0.1.0 # a named one
```

It reformats and never retypes, so this document stays the only copy. It exits non-zero if a note is
over 500 characters, or if a language the **app** ships has no note at all — both of which Play
accepts in silence and a user then reads.

The label above each block is **parsed**, not decorative: `**<Language>** — <n>/500:` on a
line of its own, with the fenced note under it. The count is what keeps a note from reaching Play
truncated, and `play-whatsnew.py` refuses a language the app ships and this section does not.

**Write these about what changed for the person reading them.** A schema migration is not a release
note; the feature it made possible is. A release where nothing user-visible changed still needs a
heading — rename it and say so in one line, so the decision is deliberate rather than made by
default.
